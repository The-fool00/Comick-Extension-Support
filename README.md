## 📖 What is Comick Loader?

Comick Loader is a **free Chrome extension** that automatically fetches chapter images from popular scanlation sites and loads them directly into Comick.dev. Say goodbye to manually uploading chapters - this extension does it all for you!

### ✨ Key Features

- 🔄 **Automatic Chapter Scraping** - Extracts images from supported sites
- 🎯 **One-Click Loading** - Load chapters to Comick with a single button
- 🌐 **Multi-Site Support** - Works with 7+ popular scanlation sites
- ⚡ **Background Processing** - No need to keep tabs open
- 🎨 **Clean Interface** - Simple and easy to use
- 🔒 **Safe & Secure** - No data collection, works locally in your browser

## 📥 Installation *(Coming Soon)*

### Prerequisites
- Google Chrome or Chromium-based browser (Edge, Brave, etc.)
- Active Comick.dev account

### Steps
1. Download the latest release from the [Releases Page](https://github.com/The-fool00/Comick-Extension-Support/releases) *(when available)*
2. Extract the downloaded `.zip` file
3. Open Chrome and go to `chrome://extensions/`
4. Enable **Developer Mode** (toggle in top-right corner)
5. Click **Load unpacked** and select the extracted folder
6. The Comick Loader icon will appear in your browser toolbar

> 🚧 **Note:** The extension is currently in development and not publicly available yet.

## 🎯 How to Use

### Basic Usage

1. **Navigate to a chapter** on any supported scanlation site
2. **Click the Comick Loader icon** in your browser toolbar
3. **Select the series** you want to load to on Comick.dev
4. **Click "Load Chapter"** - The extension will handle the rest!

### Features Explained

#### 🔍 **Auto-Detection**
The extension automatically detects which site you're on and adapts accordingly.

#### 📊 **Chapter Matching**
Smart matching system finds the correct series on Comick based on the chapter URL.

#### 🖼️ **Image Extraction**
Extracts all chapter images while filtering out ads and irrelevant content.

#### ⏱️ **Status Indicators**
- **Active** ✅ - Extension working perfectly
- **Working** ⚠️ - May have minor issues
- **Critical** 🚨 - Temporarily not working (we're fixing it!)

## ❓ Frequently Asked Questions

### Is this extension free?
**Yes!** Comick Loader is completely free to use. No subscriptions, no hidden fees.

### Is the extension open source?
**No.** While the extension is free to use, the source code is proprietary and not available for public viewing.

### Which browsers are supported?
Currently, the extension supports **Google Chrome** and all **Chromium-based browsers** (Microsoft Edge, Brave, Opera, etc.). Firefox support may come in the future.

### Does this extension collect my data?
**No.** The extension operates entirely in your browser and does not collect or transmit any personal information.

### Why isn't my favorite site supported?
We're constantly working to add more sites! Please submit a [Site Request](https://github.com/The-fool00/Comick-Extension-Support/issues/new?template=site_request.md) and we'll consider adding it.

### What if the extension stops working on a site?
Sites sometimes change their structure, which can temporarily break compatibility. Check our [Status Page](https://comick-ext.nextpagelabs.app/status) and report any issues you encounter.

## 🐛 Reporting Issues

Encountered a problem? We're here to help!

### Before Reporting
1. ✅ Check the [Status Page](https://comick-ext.nextpagelabs.app/status) - the site might have known issues
2. ✅ Try refreshing the page and restarting your browser
3. ✅ Make sure you're using the latest version of the extension
4. ✅ Check if the issue is already reported in [Issues](https://github.com/The-fool00/Comick-Extension-Support/issues)

### How to Report
When creating a new issue, please provide:

- **Site Name:** Which scanlation site were you using?
- **Chapter URL:** Link to the specific chapter
- **What Happened:** Clear description of the problem
- **Expected Behavior:** What should have happened?
- **Browser & Version:** Chrome 120, Edge 119, etc.

[**Report an Issue →**](https://github.com/The-fool00/Comick-Extension-Support/issues/new)

## 💡 Tips & Tricks

### Getting the Best Performance

1. **Keep Your Browser Updated** - Always use the latest version of Chrome
2. **One Tab at a Time** - Process one chapter before starting another
3. **Check Status Regularly** - Sites can change their structure anytime
4. **Stable Internet Connection** - Ensure good connectivity for smooth operation

### Common Solutions

**Extension Icon Not Showing?**
- Right-click the toolbar → Manage extensions → Pin Comick Loader

**Chapter Not Loading?**
- Refresh the page and try again
- Check if you're logged into Comick.dev
- Verify the site is supported

**Slow Performance?**
- Close unnecessary tabs
- Check your internet connection
- Wait a moment and retry
